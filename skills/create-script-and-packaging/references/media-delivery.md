# Deliver the requested video

This is a host execution task, not a new rendering capability inside ScriptPackage. Use the host's available tools under its existing permissions. Resolve which script or concept the request continues before producing media; do not replace it with a convenient unrelated format.

## Before rendering

Identify the essential subjects, actions, transformations, spoken content and payoff in the referenced script. Preserve a specified subject’s identity when turning that script into a video; permission to create original assets does not authorize replacing the subject or changing the concept. Check which can be produced with the available capability and authorized supplied or original assets. A video filename, a renderer's presence or permission to write a script does not establish that the required scenes can be made.

If a necessary visual, audio asset or capability is unavailable, explain that concrete gap and ask only for the missing input or agreement to a materially different treatment. Keep any completed script or usable assets. Do not imply that a text animatic, placeholder image or silent rough cut fulfills a request that still requires other visuals or narration. An explicitly requested typography video or silent edit needs no additional footage or voice merely to satisfy this check.

## Verify and hand off

Inspect the output itself before describing it as complete:

- Play or decode the file and confirm the requested duration, orientation and dimensions.
- Inspect the full video for the required subject, action, transitions and payoff. If only frame inspection is available, select frames at every storyboard beat and immediately before/after each transition, record their timestamps and uninspected intervals, and state which motion or continuity remains unverified. A matching title or sampled still cannot establish an unseen action.
- Check captions at their actual display size and timing for clipping, overlap, broken line breaks and unreadable pacing.
- Listen to required narration or audio and check timing. Report absent or unverified sound accurately; do not call an audio track verified from its metadata alone.
- Confirm that the delivered artifact is the inspected file and can be retrieved through the host's supported delivery method. A local path alone does not establish a downloadable attachment in another interface.

Correct defects with the available capability and recheck the affected result. If a requirement remains unmet or cannot be inspected, label the output as a partial draft and identify the remaining gap in the response that delivers it, rather than claiming a finished postable video. A caveat buried in a notes file cannot qualify a completion claim. Keep source permissions and hypothetical framing intact; this check does not authorize publishing.
