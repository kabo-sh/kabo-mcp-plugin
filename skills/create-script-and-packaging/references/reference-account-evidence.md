# Requested reference-account style

Reuse audience, goal, desired CTA and source scripts from the conversation through
this turn. A public post list is not a style analysis. Only the missing
audiovisual evidence is needed: a small relevant sample of existing URLs, with
transcript and actual keyframes for each. That evidence comes from
`analyze-content-video` run for those URLs; this Skill does not fetch it. Full-video
understanding being unavailable does not imply transcript/keyframes are unavailable.
Accept the existing validated VideoAnalysis contract; preserve source URL, sampled
timestamps, recognition/sampling limitations and unassessed dimensions. Inspect
pixels before asserting visual style; do not treat a noisy transcript as an exact
quote or infer spoken voice from a music/lip-sync clip. A single sample supports
that clip, not a recurring account-wide pattern or a private algorithm claim.

Use exact user-supplied product information or identifiable official product
materials. Do not resolve ambiguous brand names by guessing benefits. A routine
script can omit unsupported benefits and still be useful; proof of future sales
or guaranteed virality is not an acceptance condition. Missing evidence remains
explicit, with no repetition of unrelated research or already answered questions.
