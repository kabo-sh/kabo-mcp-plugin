## Exemplar pages (spec C, when no component fits)

Each is a finished page in the runner (structure, depth layers, timing); you pass only its
fields. **Bold** fields are required; leave out what you have nothing true for and that part
of the page goes. Text and numbers come only from your fields. When you write your own
markup instead, follow the closest page's description: its layers and layout are the bar.

## Component fields

`?` marks an optional key inside an object; `a-b x` is how many entries a list takes.

### `ui_walkthrough`

- **required** `title` (text <= 120): heading
- **required** `steps` (1-6 x {label, detail?}): the steps in order
- `kicker` (text <= 60): small line above the heading
- `subtitle` (text <= 140): line under the heading
- `numbered` (true/false): show 01, 02 ... before each step (default true)

### `street_grid_map`

- **required** `stops` (2-6 x {label, note?}): the stops in route order
- `title` (text <= 120): heading
- `kicker` (text <= 60): small line above the heading
- `subtitle` (text <= 140): line under the heading

### `vector_diagram`

- **required** `vectors` (1-6 x {label, x, y, z?}): arrows from the origin; x, y (and z in 3d) in grid units (-6..6, y up)
- `projection` (text <= 2): "2d" (flat grid, default) or "3d" (three axes over a perspective ground grid)
- `differences` (0-4 x {from, to, label?}): dashed arrows from one vector's tip to another's (two of them also shade the parallelogram)
- `title` (text <= 120): heading
- `kicker` (text <= 60): small line above the heading
- `formula` (text <= 100): formula line under the heading
- `axis_labels` ({x?, y?, z?}): axis names
- `notes` (0-3 x {label, value?}): rows under the diagram

### `data_chart`

- **required** `bars` (1-6 x {label, value, display?}): one row per bar; length = value / max
- `title` (text <= 120): heading
- `kicker` (text <= 60): small line above the heading
- `subtitle` (text <= 140): line under the heading
- `unit` (text <= 12): unit after each value
- `max` (number 0..): value of a full-length bar (default: the largest value)

### `kinetic_typography`

- **required** `headline` (text <= 140): the main line
- `highlight` (text <= 60): part of headline (exact copy) to mark
- `kicker` (text <= 60): small line above the headline
- `points` (0-4 x {text, detail?}): points under the headline
- `numbered` (true/false): big 01, 02 ... before each point (default true)

### `hud_callout`

- **required** `callouts` (1-5 x {label, x, y, value?, note?}): what to point at
- `title` (text <= 80): line across the top
- `badge` (text <= 24): small filled tag at the right of the top bar
- `waveform` (true/false): a live trace scrolling along the bottom (default false)

### `photo_collage`

- `captions` (0-4 x text <= 60): caption under each print, in refs order
- `title` (text <= 120): heading
- `kicker` (text <= 60): small line above the heading

### `split_contrast_stage`

- **required** `left` ({title, detail?, tag?}): the side being replaced
- **required** `right` ({title, detail?, tag?}): the side that wins
- `headline` (text <= 100): heading above both
- `kicker` (text <= 60): small line above the heading
- `badge` (text <= 24): small filled tag at the right of the top bar
- `highlight` (text <= 60): part of the headline (exact copy) shown in the accent colour
- `metric` ({value, label?}): big number strip under the columns (only numbers you were given)
- `strike` (true/false): strike through the left title (default true)

### `quad_interactive_spotlight`

- **required** `cells` (2-4 x {title, detail?}): the cells in spotlight order
- `headline` (text <= 100): heading
- `kicker` (text <= 60): small line above the heading
- `badge` (text <= 24): small filled tag at the right of the top bar
- `highlight` (text <= 60): part of the headline (exact copy) shown in the accent colour

### `fiber_optic_node_router`

- **required** `source` (text <= 40): text in the source box
- **required** `targets` (2-4 x {label, detail?}): the branches
- `headline` (text <= 100): heading
- `kicker` (text <= 60): small line above the heading
- `badge` (text <= 24): small filled tag at the right of the top bar
- `highlight` (text <= 60): part of the headline (exact copy) shown in the accent colour

### `frameless_counter_and_curve`

- **required** `value` (text <= 16): the big number exactly as shown (one you were given)
- **required** `series` (2-24 x number): the curve's values in order
- `label` (text <= 60): what the number measures
- `headline` (text <= 100): heading
- `kicker` (text <= 60): small line above the heading
- `badge` (text <= 24): small filled tag at the right of the top bar
- `highlight` (text <= 60): part of the headline (exact copy) shown in the accent colour
- `series_label` (text <= 30): legend name of the main curve
- `compare_label` (text <= 30): legend name of the dashed curve
- `compare_series` (2-24 x number): second, dashed curve
- `start_label` (text <= 24): label under the first point
- `end_label` (text <= 24): label under the last point
- `rows` (0-3 x {label, value}): rows under the chart

### `pip_showcase_reel`

- `captions` (0-4 x {title, detail?}): caption under each window, in refs order
- `headline` (text <= 100): heading
- `kicker` (text <= 60): small line above the heading
- `footer` ({value, label?}): number strip at the bottom

### `product_parallax`

- **required** `title` (text <= 60): product name or headline
- `subtitle` (text <= 80): line with the title
- `watermark` (text <= 14): large faint word behind the product
- `specs` (0-4 x {label, value, sub?}): hairline spec grid (only facts you were given)
- `metric` ({value, label?}): big number on the detail stages
- `cta` ({kicker?, headline?, text?, value?}): closing ribbon (at least one key)
- `meter` (true/false): pulsing bar meter on the detail stages (default false)
- `stages` (0-4 x {kicker?, headline?, text?}): text for each stage, in refs order (instead of repeating the title)
- `windows` (1-4 x [a, b]): [start, end] seconds per ref, e.g. from the voice timing; even split when left out

### `storybook_parallax`

- `title` (text <= 60): line across the top
- `chapters` (0-4 x {title?, line?}): text over each picture, in refs order
- `stardust` (true/false): drifting light motes (default true)
- `windows` (1-4 x [a, b]): [start, end] seconds per ref, e.g. from the voice timing; even split when left out

### `tracked_overlay`

- **required** `targets` (1-5 x {label, x, y, value?, note?}): points to follow, positions as seen in the base's first frame
- `links` (0-6 x [a, b]): lines joining two targets by index, e.g. [[0, 1]]
- `title` (text <= 80): line across the top
- `badge` (text <= 24): small filled tag at the right of the top bar
- `waveform` (true/false): a live trace scrolling along the bottom (default false)
